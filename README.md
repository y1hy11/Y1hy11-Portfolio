# Y1HY11 Portfolio

A minimalist resume-style portfolio website built with React, featuring responsive design, theme switching, and smooth animations. This repository contains only the documentation - the source code remains private.

[![Live Demo](https://img.shields.io/badge/Visit-TheSite-000?style=for-the-badge&color=000000&labelColor=ffffff)](https://y1hy11.github.io)

## 🎯 Project Overview

This portfolio website serves as a professional showcase with a minimalist design approach, incorporating:

- Resume-style content presentation
- Clean and modern UI/UX
- Responsive design for all devices
- Dark/Light theme functionality

## 🚀 Key Features

- Clean and minimalist design
- Dark/Light theme support
- Responsive layout
- Project showcase section
- Certificate gallery
- Skills visualization
- Interactive UI animations
- Professional experience timeline
- Contact information

## 🛠️ Technology Stack

- **Frontend Framework**: React
- **Styling**: Pure CSS3
- **Animations**: Framer Motion
- **Routing**: React Router
- **Icons**: Font Awesome
- **Build Tool**: Vite

## 📱 Responsive Design

The portfolio is fully optimized for:

- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (320px - 767px)

## 🎨 Design Philosophy

The portfolio employs a minimalist and clean design approach:

- Clear typography hierarchy
- Consistent spacing system
- Subtle motion design
- Professional color palette
- Resume-style content structure
